📦 Install M3U8 Video Downloader

Follow these steps to install the app on Ubuntu:

Step 1: Download the Installer

⬇️ Download Installer

Step 2: Make it Executable

Open a terminal and run:

chmod +x ~/Downloads/install_m3u8_app.sh

Step 3: Run the Installer

bash ~/Downloads/install_m3u8_app.sh

Step 4: Launch the App

After installation, you can launch from:

  • Terminal: m3u8-downloader
  • Apps Menu: Press Super key, search "M3U8"
  • Desktop: Double-click the shortcut
💡 Note: The installer will also install ffmpeg if needed.
